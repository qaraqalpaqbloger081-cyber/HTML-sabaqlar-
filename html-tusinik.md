# HTML degen ne? #
Bul repozitoriy HTML sabaqların qaraqalpaq tilinde berip barıw ushın arnalǵan.
## HTML haqqında Qaraqalpaq tilinde túsinik. ##
 * HTML bul - Hyper Text Markup Language.
 * Qaraqalpaq tilinde Gipertekstli belgilew tili degendi bildiredi. 
 * HTML web betlerdi  islew ushın qollanılatuǵın standart belgilew tili. 
 * HTML web betlerdiń dúzilisin sıpatlaydı. 
 * HTML kóplegen elementlerden turadı. 
 * HTML elementleri brawzerge kantentti qalay kórsetiwdi bildiredi. 
 * HTML elementleri "Bul bir baslama", "Bul bir paragraf", "Bul bir silteme" kibi kantent bólimlerin belgileydi.
---
 ## Mısal túsindirildi. ##
  * `<!DOCTYPE html>` bul hújjettiń HTML5 hújjeti ekenligin daǵazalaydı.
  * `<html>` elementi bir web bettiń túbir elementi esaplanadı.
  * `<head>` elementi HTML beti haqqındaǵı meta maǵlıwmatlardı óz ishine qamtıydı.
  * `<title>` elementi HTML betiniń baslamasın belgileydi (ol brawzerdiń baslama qatarında yamasa bet jarlıǵında kórinedi.).
  * `<body>` elementi hújjettiń gewde bólimin sıpatlaydı hám baslamalar, paragraflar, súwretler, siltemeler, kesteler, dizimler hám basqalardı óz ishine qamtıydı.
  * `<h1>` elementi eń úlken baslamanı sıpatlaydı.
  * `<p>` elementi paragraftı sıpatlaydı.
---
### HTML elementi degen ne? ###
HTML elementi baslawısh teg, kantentler hám juwmaqlawısh teg penen sıpatlanadı:

`<teg_atı>`Kantent mına jerge`</tega_atı>`

HTML elementi baslawısh tegten, juwmaqlawısh tegge shekemgi bolǵan bárlıq zat:

`<h1>` Meniń birinshi baslamam. `</h1>`

`<p>` Meniń birinshi paragrafım. `</p>`

| Baslawısh teg | Elementtiń kantenti | Juwmaqlawısh teg |
| ------------- | ------------------- | ---------------- |
| `<h1>`        | Meniń birinshi baslamam. | `</h1>`     |
| `<p>`         | Meniń birinshi paragrafım. | `</p>`    |
| `<br>`        | Joq                 | Joq              |

---
Yadıńızda saqlań: Ayırım HTML elementlerdiń kantenti joq (mısalı <br> elementi). Bul elementlerge bos elementler delinedi.
