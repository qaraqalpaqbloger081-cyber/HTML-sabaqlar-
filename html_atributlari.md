# HTML-de atributlar. #

HTML atributları HTML elementleri haqqında qosımsha maǵlıwmat beredi.

  * Bárlıq HTML elementleriniń atributları bolıwı múmkin.
  
  * Atributlar elementler haqqında qosımsha maǵlıwmat beredi.

  * Atributlar bárlıq waqıtta baslawısh teglerde jazıladı.

  * Atributlar kóbinese at/mánis tárizinde keledi: mısalı, at="mánis" (ing: name="value").

---

##### href atributı. #####

`<a>` tegi siltemeni sıpatlaydı. href atributı baylanıstıń baǵdarlaytuǵın bettiń URL-in belgileydi. 

`<a href="https://www.youtube.com">`Youtube`</a>`

---

##### src atributı. #####

`<img>` tegi HTML betine súwret qosıw ushın qollanıladı. src atributı kórsetiletuǵın súwrettiń jolın(ádresin) belgileydi:

`<img src="adam.jpg">`

src atributınıń  eki túri bar: Tolıq URL hám Salıstırmalı URL.

1. Tolıq URL. Basqa bir web saytta bar bolǵan súwretke baylanısadı.

2. Salıstırmalı URL.  Sol sayttıń óziniń bar bolǵan súwretke baylanısadı.

Yadıńızda saqlań: Bárqulla salıstırmalı URL qollanǵan jaqsı. Domen atın ózgertkenińizde baylanıs buzılmaydı.

---

##### witdh hám height atributları. #####

`<img>` tegi súwrettiń enin hám biyikligin (pikselde) anıqlaytuǵın width hám height atributların óz ishine qamtıydı.

`<img src="adam.jpg" width="500' height="600">`

---

##### alt atributı. #####

`<img>` tegi ishinde jazılıwı shárt bolǵan atribut bar. Ol alt atributı. alt atributı súwret qanday da bir sebep penen kórinbey qalsa onıń neniń súwreti ekenligin bildiretuǵın alternativ tekst esaplanadı. Mısalı internet baylanısı tómen bolǵanda, src atributında qátelik bolǵanda yamasa paydalanıwshı ekran oqıw texnologiyasınan paydalansa kerek boladı.
