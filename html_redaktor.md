# HTML ushın tekst redaktorları. #

HTML kodların jazıw ushın bir neshe tekst redaktorlar bar. Olar VS Code, Sublime Text, Notepad, TextEdit hám taǵı basqalar.

---

#### VS Code tekst redaktorı. ####

VS Code tekst redaktorı dúnyadaǵı eń tanımal hám eń jaqsı isleytuǵın tekst redaktorı. Ol web baǵdarlamalastırıwshılar tárepinen keń paydalanıladı.

Onı [code.visualstudio.com](https://code.visualstudio.com/) saytınan tartıp alıwıńız múmkin.

---

#### Sublime Text tekst redaktorı. ####

Sublime text redaktorıda eń tanımal tekst redaktorlarınan biri. Onıń VS Code-tan parqı ázzi kampyuterlerde de isleydi. Oǵada tez isleydi. Biraq interfeysi VS Code-tay qolaylı emes.

Onı [sublimetext.com](https://www.sublimetext.com/) saytınan tartıp alıwıńız múmkin.

---


#### Notepad tekst redaktorı. ####

Notepad tekst redaktorı windowslardıń ózinde bar bolǵan ápiwayı tekst redaktorı. Házirgi waqıtta oǵan bir neshe ózgeshelikler qosılǵan bolsada ( heading, yaǵnıy, baslamalar qoyıw, markdawnlar qoyıw hám taǵı basqalar) interfeysi oǵada qolaysız. Jáne VS Code hám Sublime tekstlerdegidey ekstenshın hám plaginler joq.

---

#### Mac-lerdegi TextEdit tekst redaktorı. ####

Mac-lerdegi TextEdit tekst redaktorı Mac operacion sistemasında bar bolǵan tekst redaktorı. Biraq VS Code hám Sublime Text kibi Qolaylıqlarǵa iye emes. Mısalı, VS Code hám Sublime Text kibi kodlardı bólek reńlerde kórsetiw, kodtı avtomat juwmaqlaw, terminal hám git qollanılıwınıń joqlıǵı, extension hám pluginlerdiń joqlıǵı.
