# HTML tiykarları. #

Bárlıq HTML hújjetleri hújjet túrin daǵazalawdan baslanıwı tiyis: `<!DOCTYPE html>`.

HTML hújjetiniń ózi `<html>` menen baslanadı hám `</html>` menen juwmaqlanadı.

HTML hújjetiniń ekranda kórinetuǵın bólegi `<body>` hám `</body>` tegleri arasında jayǵasadı.

----

## `<!DOCTYPE html>` daǵazası. ##

`<!DOCTYPE html>` daǵazası hújjet túrin bildiredi hám brawzerlerdiń web betlerdi durıs kórsetiwine kómeklesedi.

Hár bir HTML fayılında tek ǵana bir ret, eń birinshi qatarda jazılıwı shárt.

`<!DOCTYPE html>` daǵazası úlken/kishi háriplerge sezgir esaplanadı.
